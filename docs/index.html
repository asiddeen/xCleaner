The 5-Layer Safety Contract

Zero silent deletions. xCleaner protects your Mac's integrity at every execution step.

🛡️ 1. Hard System & Credential Blocklist

Strictly blocks macOS system roots, SIP binaries, cryptographic keys (*.pem, *.key), every .git repository, and raw VM disk images (Docker.raw).

🚦 2. 4-Tier Advisory Engine

Classifies every item as Safe (pure cache), Caution (offline audio/PWA assets), Warning (requires explicit confirmation gate), or Protected (locked).

⚡ 3. Live Running-App Lock Guard

Checks active running processes via NSWorkspace and Chromium SingletonLock files before staging to prevent corrupting databases while an app is open.

🗑️ 4. Move to Trash by Default

Uses native Finder file recycling by default. Deleted items can easily be "Put Back" from the macOS Trash. Permanent deletion requires double acknowledgment.
